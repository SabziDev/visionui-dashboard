A modern web application dashboard built with React, JavaScript and Tailwind with a
clean and responsive user interface.

- React
- Tailwind

- Axios
- TanStack Query
- i18n
- PWA

---

## ✨ Features

- Authentication
- Displaying data with interactive charts
- Dual-language panel (EN/FA)
- Skeleton UI Display States
- Fully responsive design
- Progressive Web App (PWA) with Web App Manifest, Service Worker caching, and offline capabilities

## 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/SabziDev/visionui-dashboard.git .
```

Install dependencies:

```bash
pnpm i
```

Run the project:

```bash
pnpm dev
```
