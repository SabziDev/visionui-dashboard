## 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/SabziDev/visionui-dashboard.git
```

Go to the project folder:

```bash
cd visionui-dashboard
```

Install dependencies:

```bash
pnpm i
```

Run the project:

```bash
pnpm dev
```
